# UI 디자인 프롬프트 세트

> Claude.ai (또는 Claude Code) 로 본 게임의 UI 와이어프레임 / 목업을 빠르게 생성하기 위한 재사용 프롬프트 모음.

## 📖 사용법

1. **Claude.ai 새 대화** 열기 (Artifacts 지원되는 환경 권장)
2. 아래 **🎯 마스터 시스템 프롬프트**를 첫 메시지로 그대로 복사·붙여넣기
3. 작업하고 싶은 화면의 **🖼️ 작업 프롬프트**를 이어서 붙여넣기
4. Claude가 HTML/Tailwind 목업을 Artifact로 렌더링 → 즉시 미리보기 가능
5. 결과물을 [[기획서]] 또는 별도 와이어프레임 문서에 첨부

> [!tip] 출력 형식 옵션
> - **A. HTML + Tailwind** (기본·시각적, Artifacts 렌더링)
> - **B. ASCII 와이어프레임** (빠른 스케치, 기획서에 그대로 붙이기 좋음)
> - **C. JSON UI 스펙** (개발자에게 그대로 넘기기 좋음)
>
> 작업 프롬프트 마지막 줄에 `출력 형식: A | B | C` 로 지정.

## 🎯 마스터 시스템 프롬프트

> 매번 새 Claude 대화 시작 시 첫 메시지로 그대로 붙여넣으세요.

````markdown
# 역할
너는 픽셀 모험 RPG "드래곤 콜렉션" 게임의 **UI 디자이너 / UX 기획자**야.
한국어로 작업하고, 한국 모바일 게이머에게 익숙한 UX 패턴을 우선한다.

# 게임 정체성
- 장르: **노드 진행형 픽셀 모험 RPG + 드래곤 콜렉션 + ARG 보물찾기**
- 레퍼런스: 카피바라 Go! (노드 진행), 퍼즐앤드래곤 (흡수 레벨업), Dragon Cave (콜렉션·발견), Slay the Spire (유물·아이템 이중 구조)
- 그래픽: **픽셀 아트 2D**, 모바일 친화 (세로 스크롤)
- 플레이어 캐릭터는 **시각적으로 노출되지 않음** (1인칭 카메라, 시점 = 카메라)

# 핵심 시스템 요약
- 파티: **드래곤 5마리** (각 드래곤은 **아이콘**으로 표현)
- 진화: 알 → 해츨링 → 성체 → 초월체 (4단계, 레벨 캡 20/40/60)
- 전투: **자동 턴제** + 스킬 수동 온/오프 + **드래곤별 분노 게이지** + 8속성 상성
- 모험: 지역 선택 → **20~50 단계** 노드 진행 → 갈림길 (다음 노드 종류 미리 보임)
- 노드: ⚔️전투 / ❤️회복 / 👤NPC / 📦상자 / ❓이벤트 / 🌀갈림길 / 👑보스
- 자원: **아이템**(모험 중 소모, 외부 반출 X) / **유물**(영구·캐릭터 슬롯, 시작 3개)
- 콜렉션: **시즌제** + 시즌 감쇠 모델 + 교배 시스템
- 8속성: 🔥불 💧물 🌿풀 🪨땅 ⚡번개 ❄️얼음 ☀️빛 🌑어둠

# 비주얼 스타일 가이드
- 컬러 팔레트: **레트로 픽셀 + 따뜻한 톤** (#2b1e3d 짙은 보라, #f4d35e 따뜻한 노랑, #e63946 액센트, #06d6a0 포인트)
- 폰트: **픽셀 폰트** (Press Start 2P, Galmuri11) — 한글은 Galmuri 시리즈 권장
- 모서리: 둥글지 않은 8px 사각 / 픽셀 보더
- 애니메이션: **이징은 step-end** (픽셀 게임 느낌), 부드러운 곡선 X
- 아이콘: **이모지로 placeholder 표현 가능** (🥚 🐲 ⚔️ 🛡️ 등)

# UX 원칙
1. **모바일 세로 우선** (375×812 기준), 데스크탑은 중앙 정렬 게임 영역
2. **한 화면 = 한 의사결정** (선택지/액션이 명확)
3. **상태 가시성** (HP / 분노 게이지 / 스킬 온오프가 항상 보임)
4. **발견의 여백** — 도감의 빈 슬롯, 안개 낀 미답 지역 등 "탐험 동기" 요소
5. **드래곤이 주인공** — 드래곤 아이콘이 UI 중심, 플레이어 캐릭터는 등장 X

# 출력 규칙
- 기본 형식은 **HTML + TailwindCSS** (Artifacts에서 즉시 렌더링되도록)
- 픽셀 폰트는 Google Fonts 또는 CDN으로 로드 (`Press Start 2P`, `Galmuri11`)
- 모든 텍스트는 한국어 (영문 병기는 필요 시만)
- 더미 드래곤·NPC 이름은 [[기획서]] 정의된 이름 사용
  (예: 잿불이/파이어 드래곤/블레이즈윙, 무영 할아범, 호롱이, 달비, 보부)
- 코드 위에 **간단한 의도 설명 5줄 이내** 한국어 코멘트
- 모바일(375px) 기준으로 디자인 후 데스크탑 확장은 max-width 제한

# 답변 시 워크플로우
1. **요구 화면 한 줄 요약** (이 화면이 뭘 하는 화면인지)
2. **UI 컴포넌트 리스트** (헤더, 본문, 액션 영역 등)
3. **상호작용 흐름** (탭/스와이프 시 무슨 일이 일어나는지)
4. **HTML/Tailwind 코드** (Artifact)
5. **다음 디자인 결정 제안** (이 화면 이후 자연스럽게 이어질 화면 또는 미정 사항)

준비됐으면 "준비 완료. 어떤 화면을 디자인할까요?" 라고만 답변해줘.
````

## 🖼️ 화면별 작업 프롬프트

### 1) 🏘️ 시작 마을 (Tranquil Hamlet) 메인 화면

````markdown
[화면 1: 시작 마을 메인]

다음 시설/NPC가 한 화면에 자연스럽게 배치된 픽셀 마을 화면을 디자인해줘:

- 🥚 **둥지**(중앙) — 호롱이 NPC, 교배 의뢰
- 🏥 **회복시설** — 달비 NPC, 빈사 회복
- 🛒 **상점** — 보부 NPC, 아이템·유물 슬롯 확장
- 🪧 **여행자 게시판** — 사이팅 통계 자동 게시
- 📖 **도감** — 콜렉션 진입
- 🗺️ **지역 선택** 버튼 (월드맵으로 진입)

상단: 플레이어 자원 바 (코인, 진화석, 초월석, 현재 슬롯 수)
하단: 4탭 네비게이션 (마을/도감/스크롤/상점)

세로 스크롤 모바일 기준. 각 시설은 탭하면 모달/페이지 전환.
출력 형식: A
````

````markdown
시즌 1 "잃어버린 알의 계곡" 6지역을 보여주는 월드맵 화면:

상단: 시즌 진행도 바 + 시즌 종료까지 D-day
출력 형식: A
````

### 3) 🌲 모험 진입 / 노드 진행 (세로 스크롤)

````markdown
[화면 3: 모험 진행 - 세로 스크롤 노드맵]

카피바라 Go! 스타일 노드 진행 화면을 디자인해줘:

- **세로 스크롤**, 맵이 위로 흐르는 느낌
- 현재 단계가 화면 중앙, 위로 다음 단계들이 보임

상단 HUD:
- 현재 지역명 + 단계 X/30
- 5마리 파티 미니 아이콘 (HP 바 + 분노 게이지)

하단: "다음 노드로" 버튼 (갈림길 시 비활성)
````

### 4) ⚔️ 전투 화면

````markdown
[화면 4: 전투 화면]

자동 턴제 + 분노 게이지 + 속성 상성이 한눈에 보이는 화면:

- **상단**: 적 진영 (1~3마리, 픽셀 아이콘 + HP 바 + 속성 아이콘)
- **중앙**: 데미지 / 효과 텍스트 플로팅 영역 (상성 효과 시 1.5× / 0.5× 표시)
- **하단**: 우리 파티 5마리 (가로 정렬)
  - 드래곤 아이콘
  - HP 바
  - **분노 게이지 바** (0~100, 가득 차면 발광)
  - 스킬 토글 ON/OFF (각 드래곤별 작은 스위치)
  - 속성 아이콘
- **하단 우측**: 아이템 슬롯 (치료제, 강화 물약 등 — 탭으로 사용)

자동 진행이 기본이지만 1.5×/2×/일시정지 버튼 제공.
빈사된 드래곤은 회색 + 💀 표시.

출력 형식: A
````

### 5) 📖 도감 (스크롤)

````markdown
[화면 5: 도감 — Scroll]

발견한 드래곤 + 미발견 빈 슬롯이 함께 보이는 도감:

- **상단 필터**: 시즌 / 속성 / 트랙(동/서/고유) / 진화 단계 / 등급
- **그리드**: 종별 카드 (3열)
  - 발견됨: 드래곤 아이콘 + 한글명 + 영문명 + 속성
  - 미발견: ❓ 검은 실루엣 + "???"
  - **유출 단서가 있는 미발견 종**: 실루엣 위에 ✨ + 짧은 단서 (예: "북쪽 바람이…")
- **상단 통계**: 도감 완성도 (예: 12/45) + 시즌 마스터 진척

카드 탭 시: 드래곤 상세 화면(다음 프롬프트)으로 진입.

발견 피드(하단 떠다님): "○○님이 새로운 드래곤을 최초로 부화시켰습니다!"

출력 형식: A
````

### 6) 🐲 드래곤 상세 / 흡수 / 진화 화면

````markdown
[화면 6: 드래곤 상세 페이지]

특정 드래곤(예: 잿불이 → 파이어 드래곤 → 블레이즈윙) 상세 화면:

- **상단**: 큰 픽셀 아이콘 + 진화 단계 표시 + 한글/영문 이름

- **스킬 슬롯**: 종 고유 스킬 1개 + 진화 시 획득한 랜덤 스킬들
  - 각 스킬 ON/OFF 토글, 분노 시 발동 여부 표시
- **액션 버튼 3개**:
  - 🔄 **흡수**: 다른 드래곤 선택해 경험치 흡수 (퍼즐앤드래곤 방식)
  - ✨ **진화**: 조건 충족 시 진화석/초월석 소모 (UI에 조건 명시)
  - 🤝 **교배 의뢰**: 둥지로 이동 (호롱이 NPC)
- **하단**: 부화 단서 / 도감 설명 / 첫 발견 일시

출력 형식: A
````

### 7) 💎 유물 슬롯 / 인벤토리

````markdown
[화면 7: 유물 슬롯 + 보유 유물 목록]

- **상단**: 캐릭터(페르소나) 슬롯 영역

  - 장착된 유물은 픽셀 아이콘 + 효과 요약

  - 카테고리 필터: 🛡️방어 / ⚔️공격 / 💎자원 / 🧙단서 / 🎲메타 / 🐲종족
  - 카드: 유물 아이콘 + 이름 + 효과 한 줄 + 슬롯 비용(1~2)
  - 장착됨 표시 (체크) / 미장착 (탭하면 슬롯 선택 모달)
- **상단 통계**: 활성 슬롯 수 / 총 유물 보유 수

출력 형식: A
````

### 8) 🥚 둥지 / 교배 화면

````markdown
[화면 8: 둥지 - 호롱이 NPC 교배 의뢰]

- **하단**: "교배 시작" 버튼 + 쿨다운 정보 (기본 7일)
- **사이드**: 진화석/초월석 보유량 (교배 결과 알 부화에 필요)
````
