# 게임 디자인 철학

## 1. 게임 컨셉 개요

> [!tip] 한 줄 소개
> "드래곤은 어떻게 얻는지조차 비밀이다. 위키와 디스코드가 게임의 일부다."

- **레퍼런스**: [Dragon Cave](https://dragcave.net) 에서 영감을 받은 [[드래곤 콜렉션]] 게임
- **그래픽**: **픽셀 아트** (확정)
- **장르**: **모험 RPG** — 맵에서 지역 선택 → 진입 → 탐험·전투·상자·NPC 인터랙션
- **핵심 차별점**: **"보물찾기" 기반 발견형 게임**
    - 각 드래곤은 게임 곳곳에 숨겨져 있음
    - 유저가 어떻게 얻는지 직접 찾아내야 함
- **디자인 방향**: **커뮤니티 협력형 (Fez/ARG 스타일)**
    - 한 명으로는 못 푸는 퍼즐
    - 위키/디스코드 활동이 게임의 일부

### 도입하는 / 도입하지 않는 시스템

| 도입 ✅ | 도입 안 함 ❌ |
|---|---|
| 시즌제 + 감쇠 모델 | **혈통(Lineage) 시스템** |
| 교배 + 시즌 교차 교배 | |
| 시즌 간 스토리 연결 | |
| 시즌 마스터 보상 | |
| 픽셀 모험 RPG (맵·전투·상자·NPC) | |

## 2. Dragon Cave 레퍼런스 분석

> [!example] 왜 Dragon Cave가 20년간 살아남았는가
> 단순함, 저압력, 다양한 플레이스타일, 비강제 과금.

### 게임 구조

- 무료 어돕터블(adoptable) 게임
- **알 → 해츨링 → 성체** 3단계 성장 사이클
- 알은 바이옴, 버려진 페이지(Abandoned Page), 번식(Breeding)으로 획득

### 부화/성체화 메커니즘

| 단계 | 조건 |
|---|---|
| 부화(Hatch) | 약 **400 unique views** |
| 성체화(Grow) | 약 **1,000 unique views** |
| 알 수명 | 7일 |
| 패널티 | 너무 빠른 조회는 알을 병들게 함 |

### 주요 시스템

- **바이옴 시스템** (2011년 도입)
- **번식**: 주 1회 쿨다운, 4개 알 중 1개 보관 가능
- **Magi 드래곤의 Teleport** 기능으로 트레이드
- **시크릿/단종 드래곤** → 컬렉션 욕구 자극

### 비주얼

- 픽셀 아트 스프라이트 (해츨링 17×10px)
- 카툰풍

### 인기 비결

- 단순한 집중점
- 저압력 플레이
- 다양한 플레이스타일 수용
- 비강제 과금

# 핵심 시스템

## 3. 핵심 게임 루프

### 3-1. 드래곤 성장 사이클

```
알(Egg) → 해츨링(Hatchling) → 성체(Adult)
```

> [!warning] 핵심 비틀기
> 각 드래곤마다 **부화 방식이 다름**. 부화 자체가 [[수수께끼]]다.
> 같은 알에서 **부화 방식에 따라 다른 변종**이 나오는 것도 가능.

### 3-2. 플레이어 메인 루프 (모험 RPG)

```
🌍 월드 맵 (Overworld)
   └── 🏞️ 지역 선택 (Region Pick)
        └── 🌲 진입 후 탐험 (Zone Exploration)
             ├── 🗡️ 야생 드래곤 조우 → 전투
             ├── 📦 보물 상자 (알 / 아이템 / 단서)
             ├── 👤 NPC 인터랙션 (퀘스트 / 루머 / 거래)
             └── 🚪 숨겨진 입구 (서브 던전)
```

> [!tip] 발견 시스템과 모험 메커닉의 연결
> 기존 발견 시스템(단서·트리거·협력)이 **NPC 대화·상자·환경 오브젝트**로 자연스럽게 분배된다.

---

## 3-3. 모험 게임 시스템 (맵 / 전투 / 상자 / NPC)

### 맵 구조 (3계층)

| 계층 | 설명 | 예시 |
|---|---|---|
| **🌍 월드 맵** | 전체 세계 조망, 지역 선택 진입점 | 시즌별 테마 적용 |
| **🏞️ 지역(Region)** | 시즌과 연동된 바이옴 단위 | 화산 능선, 안개의 숲 |
| **🌲 존(Zone)** | 실제 탐험 공간, 격자/타일 기반 | 던전 내부, 마을, 들판 |

### 시스템 ↔ 모험 메커닉 매핑

| 시스템 | 모험 게임에서의 형태 |
|---|---|
| 알 획득 | 상자 / 둥지 / 보스 드롭 / 퀘스트 보상 |
| 부화 단서 | NPC 대화 / 책 / 비석 / 환경 오브젝트 |
| 비대칭 정보 | 유저마다 NPC 대사가 미묘하게 다름 |
| 사이팅 | "여행자 게시판" NPC가 최근 목격담 보고 |
| [[#15. 시즌 시스템|시즌 감쇠]] | 지역마다 "시대"가 흐름 — 과거 지역은 황폐화 |
| [[#16. 교배 시스템|교배]] | 둥지(Nest) 시설 — 전용 마을에 위치 |

### 전투 시스템 (방향성 — 미정)

> [!warning] 핵심 결정 필요
> 전투의 목적이 게임 톤을 결정한다. 4가지 모델 중 선택.

| 모델 | 설명 | 분위기 |
|---|---|---|
| **A. 포획형 (Pokemon)** | 약화시킨 후 알 획득 | 친근/모험 |
| **B. 길들이기형 (Monster Hunter)** | 반복 조우로 신뢰 쌓기 | 깊이 있음 |
| **C. 평화형 (Stardew)** | 전투 없음, 환경 상호작용 | 힐링 |
| **D. 혼합형 (추천)** | 종마다 다른 획득 방식 | 보물찾기에 부합 |

> [!tip] 추천: **D. 혼합형**
> "이 드래곤은 어떻게 잡지?"가 또 하나의 미스터리가 된다.

### 상자(Chest)의 역할

- 알 / 아이템 / 단서 조각 / 화폐 등 다양한 보상
- **희귀 상자**: 특정 조건 충족 시에만 출현 (열쇠, 시간, 의식)
- **거짓 상자(Mimic)**: 보물찾기 페이크 — 단서로 진실 공개

### NPC 인터랙션

- **루머 NPC**: 무작위 단서 흘리기
- **상인 NPC**: 부화 도구·먹이·재료 거래
- **퀘스트 NPC**: 다단계 의식의 시작점
- **여행자 게시판**: 다른 플레이어 사이팅 통계 노출
- **둥지지기**: 교배 의뢰 + 조합 힌트 보유

## 4. 다양한 부화 방식 카테고리

| 카테고리 | 예시 |
|---|---|
| **입력 기반** | 탭 누적, 롱프레스, 흔들기, 문지르기, 리듬 두드리기 |
| **환경 기반** | 온도 조절, 바이옴 배치, 낮/밤 사이클, 날씨 |
| **시간 기반** | 고정 대기, 정각 진행, 누적 접속일 |
| **자원/케어** | 먹이(고기/물고기/과일/보석), 재료 수집, 알 희생 |
| **미니게임** | 껍질 퍼즐, 수수께끼, 패턴 매칭, 음표 따라하기 |
| **조건부** | 다른 드래곤 보유 조건, 시간대 한정, 확률 발동 |

## 5. 보물찾기 / 발견 디자인 원칙

> [!tip] 황금률
> "드래곤 = 수수께끼. 어떻게 얻는가가 곧 콘텐츠다."

- 드래곤 = 수수께끼 (어떻게 얻는가가 콘텐츠)
- 단서는 게임 곳곳에 (텍스트 / 비주얼 / 사운드 / 환경)
- **명확한 답은 없음** (추리 가능해야 함)
- **커뮤니티 공유 유도**

## 6. 드래곤 숨기기 방법 (획득 트리거)

### 시간 / 주기

- 특정 시각에만 출현
- 현실 날짜 연동 (보름달, 일식)
- [[시즌 시스템|시즌]] 이벤트 한정

### 행동 시퀀스

- 순서가 있는 의식
- 반복 행동
- 숨겨진 조합

### 환경 탐색

- 픽셀 사냥(pixel hunt)
- 카메라 줌/팬
- **반전된 조작** (거부해야 등장)

### 역설 / 희생

- 알 깨뜨리기
- 컬렉션 리셋
- 빈 스크롤 보상

### 사회적

- 트레이드 전용
- 연쇄 양도
- 다른 플레이어 관찰

### 메타 / 4차원의 벽

- 알 설명문 첫 글자
- URL 트릭
- 콘솔 단서

## 8. 단서 전달 시스템

> [!warning] 핵심 원칙
> **스포일러 방지가 가장 중요하다.** 너무 친절하면 보물찾기가 아니다.

| 레이어 | 예시 | 역할 |
|---|---|---|

## 11. 드래곤 5종 예시 디자인

### 1) 별자리 드래곤 (Constellation / Stellaris)

- 12명에게 각각 별 1개 좌표 분배
- 합쳐서 별자리 완성
- 순서대로 클릭 → 별자리 이름 입력
- **최초 발견자만 정통**, 이후 변종

### 2) 메아리 드래곤 (Echo)

- 알 설명에 랜덤 음절 1개
- 7명+ 음절 조합해 주문 완성 → 채팅창 입력
- 매주 음절 셔플

### 3) 회유 드래곤 (Migration)

- 1시간마다 다른 바이옴 출현, **위치 비공개**
- 커뮤니티 목격 정보로 패턴 분석 → 다음 위치 예측

### 4) 거울 드래곤 (Mirror)

- 두 플레이어가 알 절반씩 보유 (좌/우 비대칭)
- 같은 분 안에 트레이드 + **동시 클릭**

### 5) 예언자 드래곤 (Oracle)

- 랜덤 플레이어에 예언서 조각 드롭
- 21개 모이면 의식 절차 공개 (요일 + 드래곤 3종 + 시각)

## 12. 필수 인프라 시스템

> [!tip] 인프라가 콘텐츠다
> 발견 자체를 콘텐츠로 만들려면 **공유/관찰/추적** 시스템이 먼저 필요하다.

- **발견 피드**: "○○님이 최초로 부화시켰습니다!"
    - 영구 명예 마크
    - 변종(prismatic) 보상
    - 단, **방법은 비공개**
- **도감 빈 슬롯**: 검은 실루엣 + 물음표, 가끔 유출 단서
- **공개 트레이드/관찰**: 다른 플레이어 스크롤·알 설명문 열람 가능
- **사이팅 시스템**: 익명 카운트로 통계 페이지 = 실질적 위키
- **외부 친화**: 알 영구 URL, 스크린샷 워터마크 단서

# 핵심 메커닉 (시즌제 + 교배)

> [!warning] 가장 중요한 두 시스템
> [[시즌 시스템]]과 [[교배 시스템]]은 이 게임의 **수명과 메타게임 깊이**를 결정한다.
> MVP 후반에 반드시 도입.

## 15. 시즌 시스템

### 개요

- 각 시즌마다 **정해진 드래곤 풀**이 있음
- 시즌이 끝나면 해당 드래곤들은 **발견 난이도가 대폭 상승** (감쇠 모델)
    - ⚠️ "발견 불가"가 아닌 **"점점 더 어려워짐"** — 신규 유저에게도 희망 유지
- 시즌 종료된 드래곤은 [[교배 시스템|교배(breeding)]]로도 획득 가능

### 15-1. 시즌 감쇠 모델 (Decay Model) ⭐

> [!warning] 핵심 메커닉
> 각 시즌이 지날 때마다 과거 드래곤은 점점 더 희박해진다.
> "발견 불가"가 아닌 **"추적의 묘미"**.

#### 단계별 감쇠 예시 (시즌 1의 불꽃 드래곤)

| 단계 | 시즌 | 난이도 | 출현 조건 |
|---|---|---|---|
| 활성 | 시즌 1 | 일반 | 화산 지역에 빈번히 출현 |
| 감쇠 1 | 시즌 2 | 어려움 | 출현률 1/5, 야간에만 |
| 감쇠 2 | 시즌 3 | 매우 어려움 | 출현률 1/20, 특정 NPC 퀘스트 클리어 시 |
| 잔재 | 시즌 4 | 희귀 | 보물상자 0.5%, 특정 의식 후 |
| 전설 | 시즌 5+ | 거의 불가 | 야생 출현 종료, 회상 이벤트 시 부활 |

#### 감쇠 메커니즘 옵션 (조합 가능)

- **출현률 감소**: 확률 단계적 하향
- **시간/조건 추가**: "특정 시간대만", "특정 아이템 보유 시만"
- **지역 축소**: 처음 3개 지역 → 2개 → 1개 → 비밀 지역
- **단계별 잠금 해제**: NPC 퀘스트 / 미니 ARG 클리어해야 만남 가능

#### 감쇠 모델의 장점

- 신규 유저가 **이론상 모든 드래곤을 만날 수 있음** (희망 유지)
- 고인물은 **추적의 묘미** (어디 있는지 찾아내는 재미)
- 시즌 마스터의 **희소성 가치 유지**

### 15-2. 시즌 간 스토리 연결 ✅

- 각 시즌은 **세계관 챕터**처럼 전개
- 예: "드래곤 군주의 봉인 → 봉인 해제의 조짐 → 군주의 귀환…"
- 시즌이 진행될수록 **세계가 변화** (지역 황폐화, 새 지역 개방)
- 과거 시즌 NPC들이 **현재 시즌에 흔적**을 남김 (편지, 비석, 메아리)

### 15-3. 시즌 교차 교배 ✅

- 시즌 N의 드래곤과 시즌 N+1의 드래곤을 **교배 가능**
- 결과로 **시즌 외 한정 신규 종** 등장 가능
- 자세한 메커닉: [[#16. 교배 시스템]]

### 15-4. 시즌 마스터 보상 ✅

> [!example] 시즌 도감 100% 달성자 혜택

| 보상 | 설명 |
|---|---|
| **시즌 마스터 칭호** | 영구 표시, 도감/프로필 노출 |
| **변종(Prismatic) 드래곤** | 시즌 한정 색상의 특별 변종 |
| **다음 시즌 얼리 액세스** | 1주일 먼저 시즌 N+1 진입 가능 |
| **회상 이벤트 우선권** | 과거 시즌 드래곤 재출현 시 우선 알림 |
| **특별 NPC 호의** | 마스터 전용 거래/퀘스트 잠금 해제 |

### 효과 정리

| 효과 | 설명 |
|---|---|
| **FOMO 강화** | "지금 잡는 게 가장 쉽다" → 시즌 중 활발한 플레이 |
| **후발주자 배려** | 감쇠 모델 + 교배로 결국 도달 가능 |
| **트레이딩 가치 상승** | 시즌 종료 종은 점점 희귀해짐 |
| **메타게임 깊이** | "어떤 시즌 종을 보존할까" 전략 |
| **장기 플레이 유도** | 시즌 마스터 → 다음 시즌 → 누적 명예 |

> [!note] 시즌제와 위키 박제 방지
> 시즌별 단서 셔플은 [[#14. 흔한 함정과 대응|위키 박제 함정]]의 자연스러운 해결책이기도 하다.

## 16. 교배 시스템

### 기본 규칙

- 교배에는 **드래곤 2마리** 필요
- 결과 가능 종:
    - 부모 두 종 중 하나
    - 두 종의 **조합으로 발생 가능한 신규 종**
- 조합 발견 자체가 또 하나의 콘텐츠 (어떤 조합이 어떤 결과를 내는지 실험)
- **시즌 종료 드래곤도 교배 결과로 등장 가능** → 신규 유저도 도감 완성 가능

### 조합 예시

| 부모 A | 부모 B | 가능한 결과 |
|---|---|---|
| 불 드래곤 | 물 드래곤 | 증기 드래곤 |
| 불 드래곤 | 땅 드래곤 | 용암 드래곤 |
| 시즌1 드래곤 A | 시즌2 드래곤 B | 시즌 외 한정 신규 종 C (오직 교배로만) |

### 데이터 구조

```js
const breedingRecipe = {
  parents: ["fire_dragon", "water_dragon"],
  possibleOutcomes: [
    { dragonId: "fire_dragon", weight: 30 },
    { dragonId: "water_dragon", weight: 30 },
    { dragonId: "steam_dragon", weight: 40 }  // 조합 신규
  ],
  cooldown: "7d",
  unlockCondition: null  // 또는 "discovered_steam_first"
}
```

> [!tip] 교배 + 발견 = 이중 보물찾기
> 어떤 조합이 어떤 드래곤을 만드는지 자체가 [[보물찾기]]의 또 다른 레이어다.
> 자세한 레시피는 [[교배 조합 레시피]] 문서 참조 (작성 예정).
