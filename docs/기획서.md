# 게임 디자인 철학

## 1. 게임 컨셉 개요

> [!tip] 한 줄 소개
> "드래곤은 어떻게 얻는지조차 비밀이다. 위키와 디스코드가 게임의 일부다."

- **레퍼런스**: [Dragon Cave](https://dragcave.net) 에서 영감을 받은 [[드래곤 콜렉션]] 게임
- **그래픽**: **픽셀 아트** (확정)
- **장르**: **모험 RPG** — 맵에서 지역 선택 → 진입 → 탐험·전투·상자·NPC 인터랙션
- **핵심 차별점**: **"보물찾기" 기반 발견형 게임**
    - 각 드래곤은 게임 곳곳에 숨겨져 있음
    - 유저가 어떻게 얻는지 직접 찾아내야 함
- **디자인 방향**: **커뮤니티 협력형 (Fez/ARG 스타일)**
    - 한 명으로는 못 푸는 퍼즐
    - 위키/디스코드 활동이 게임의 일부

## 2. Dragon Cave 레퍼런스 분석

> [!example] 왜 Dragon Cave가 20년간 살아남았는가
> 단순함, 저압력, 다양한 플레이스타일, 비강제 과금.

### 게임 구조

- 무료 어돕터블(adoptable) 게임
- **알 → 해츨링 → 성체** 3단계 성장 사이클
- 알은 바이옴, 버려진 페이지(Abandoned Page), 번식(Breeding)으로 획득

### 부화/성체화 메커니즘

| 단계 | 조건 |
|---|---|
| 부화(Hatch) | 약 **400 unique views** |
| 성체화(Grow) | 약 **1,000 unique views** |
| 알 수명 | 7일 |
| 패널티 | 너무 빠른 조회는 알을 병들게 함 |

### 주요 시스템

- **바이옴 시스템** (2011년 도입)
- **번식**: 주 1회 쿨다운, 4개 알 중 1개 보관 가능
- **Magi 드래곤의 Teleport** 기능으로 트레이드
- **시크릿/단종 드래곤** → 컬렉션 욕구 자극

### 비주얼

- 픽셀 아트 스프라이트 (해츨링 17×10px)
- 카툰풍

### 인기 비결

- 단순한 집중점
- 저압력 플레이
- 다양한 플레이스타일 수용
- 비강제 과금

# 핵심 시스템

## 3. 핵심 게임 루프

### 3-1. 드래곤 성장 사이클

```
알(Egg) → 해츨링(Hatchling) → 성체(Adult)
```

> [!warning] 핵심 비틀기
> 각 드래곤마다 **부화 방식이 다름**. 부화 자체가 [[수수께끼]]다.
> 같은 알에서 **부화 방식에 따라 다른 변종**이 나오는 것도 가능.

### 3-2. 플레이어 메인 루프 (노드 진행형 모험 RPG)

> [!example] 카피바라고(Capybara Go!) 스타일
> 일차 단위 노드 진행 + 갈림길 선택 + 자동 턴제 전투 구조를 참고.

```
[월드맵: 지역 선택]
        ↓
[지역 진입 → 모험 시작]
        ↓
┌─── 단계 1 ───┐  ◀ 노드 이벤트 (전투 / 회복 / NPC / 상자 / 이벤트)
│   ↓ 갈림길   │
├─── 단계 2 ───┤
│   ↓         │   ◀ 세로 스크롤, 맵이 위로 흐르는 느낌
├─── 단계 3 ───┤      플레이어 캐릭터는 보이지 않음 (시점 = 카메라)
│   ...       │
└─── 단계 N ───┘  ◀ N = 5 ~ 50 (지역 클리어 횟수에 비례)
        ↓
[모험 종료 → 보상 정산 → 회복시설]
```

### 3-3. 모험 시스템 상세

#### 단계(Stage) 점증 시스템 ⭐

| 항목 | 값 |
|---|---|
| **시작 단계 수** | **20** |
| **최대 단계 수** | **50** |
| **증가량** | 지역 클리어 1회당 **+10** |
| **만렙까지** | 3회 클리어 (20 → 30 → 40 → 50) |
| **의미** | 더 깊이 진입 → 더 깊은 보상 / 더 희귀한 알 / 더 위험 |

> [!example] 단계 점증 곡선
> | 클리어 횟수 | 단계 수 |
> |---|---|
> | 0회 (첫 진입) | 20 |
> | 1회 | 30 |
> | 2회 | 40 |
> | 3회+ | 50 (최대) |

> [!tip] 시즌 감쇠와의 연동
> 시즌1 드래곤은 시즌2부터 "단계 30+ 노드"에서만 출현, 시즌3엔 "단계 45+에 1%" 식으로 자연스럽게 추적 난이도 증가. 깊은 단계 도달 능력 자체가 [[#15. 시즌 시스템|감쇠 모델]]의 핵심 매개.

#### 노드(Node) 종류

| 아이콘 | 종류 | 내용 |
|---|---|---|
| ⚔️ | 전투 | 야생 드래곤/적과 자동 턴제 전투 |
| ❤️ | 회복 | HP 회복 / 가벼운 버프 |
| 👤 | NPC | 대화 · 단서 · 거래 · 퀘스트 |
| 📦 | 상자 | 알 / 아이템 / 유물 / 화폐 |
| ❓ | 이벤트 | 텍스트 분기 (선택지로 결과 변동) |
| 🌀 | 갈림길 | 다음 노드 2개 중 선택 |
| 👑 | 보스 | 단계 끝 / 알 보장 드롭 |

#### 갈림길(Branching) 정보 공개

- **다음 노드 종류는 사전에 보임** (카피바라고 방식)
- 종류는 보이지만 **결과/세부는 미공개** ("전투인 건 알지만 어떤 적이 나올지는 모름")
- 갈림길 선택이 **비대칭 정보의 천연 도구** — 같은 단계에서 누구는 NPC를 만나고 누구는 전투, 단서가 갈림

#### 시점 / 비주얼

- **플레이어 캐릭터 미노출** — 1인칭 카메라 시점
- **세로 스크롤** — 모바일 친화 + 진입감
- 맵이 위로 흐르는 효과 → "전진" 느낌
- 픽셀 아트 노드 + 픽셀 아이콘 드래곤

### 3-4. 파티 시스템

| 항목 | 값 |
|---|---|
| **파티 규모** | **드래곤 5마리** |
| **표현** | 각 드래곤 **아이콘화** (전투 시 픽셀 아이콘) |
| **편성** | 모험 진입 전 선택, 모험 중 변경 불가 (잠정) |
| **분노 게이지** | **드래곤마다 개별** 누적 |
| **스킬** | 드래곤마다 **수동 온/오프** 가능 (자동 발동 on/off) |

> [!note] 드래곤이 곧 플레이어
> 캐릭터가 없으니 드래곤 5마리가 사실상 플레이어의 분신. 파티 빌드가 곧 플레이 스타일.

#### 파티 빌드 고려 요소
- 5마리 **속성 분배** (상성 대응)
- 5마리 **진화 단계 조합** (초월체 1마리 + 성체 4마리?)
- **유물 슬롯**과의 시너지 (속성 강화 유물 등)

### 3-5. 드래곤 RPG 요소 ⭐

> [!tip] 핵심 컨셉
> **퍼즐앤드래곤(Puzzle & Dragons) 방식의 흡수 레벨업** + **4단계 진화 트리**.
> 모든 알이 의미 있다 — 안 쓰는 드래곤은 **재료**로 가치를 가짐.

#### 레벨업: 흡수(Absorption) 방식

- 드래곤은 **다른 드래곤을 흡수**해서 레벨업
- 흡수된 드래곤은 사라짐 (재료화)
- 같은 종 / 같은 속성 흡수 시 **보너스 경험치** 가능 (잠정)

> [!example] 흡수의 부산 효과
> "약한 알도 버려지지 않는다." 모든 획득 알이 결국 어딘가에 쓰인다 → 모험 보상 가치 일관 유지.

#### 진화 트리 (4단계) + 레벨 캡

```
🥚 알(Egg) → 🐣 해츨링(Hatchling) → 🐲 성체(Adult) → ✨ 초월체(Transcendent)
                Lv. 1~20            Lv. 1~40         Lv. 1~60
```

| 단계 | 레벨 캡 | 진화 조건 |
|---|---|---|
| 🥚 알 | — | 부화 조건 충족 (드래곤마다 다름) |
| 🐣 해츨링 | **20** | 전 단계 최대 레벨 + **진화석** |
| 🐲 성체 | **40** | 전 단계 최대 레벨 + **진화석** |
| ✨ 초월체 | **60** | 전 단계 최대 레벨 + **진화석 + 초월석** |

> [!warning] 진화 필수 조건
> 모든 진화는 **이전 단계 최대 레벨 도달 + 재료 소모**가 동시에 필요하다.

#### 경험치 곡선 (퍼즐앤드래곤 방식)

| 항목 | 값 |
|---|---|
| **Lv. 100 누적 EXP** | **1,000,000 (100만)** |
| **곡선 형태** | 지수 상승 |
| **육성 난이도 배수** | **0.5x / 1x / 1.5x / 2x / 3x** |

> [!note] 배수의 의미
> 희귀도/등급별로 같은 레벨이라도 필요 경험치가 다르다.
> 예: Common = 1x, Rare = 1.5x, Epic = 2x, Mythic = 3x, 이벤트 한정 = 0.5x (가속)

#### 스킬 시스템

| 단계 | 스킬 |
|---|---|
| 종 고유 스킬 | 모든 동일 종은 같은 기본 스킬 보유 |
| 진화 시 획득 | **랜덤 스킬 획득** (해츨링→성체 시 + 성체→초월체 시) |

> [!note] 같은 종이라도 빌드 다양화
> 진화 랜덤 스킬 덕분에 **같은 종도 개체차**가 생긴다 — 트레이드/콜렉션 가치 추가.

#### 스탯
- HP, 공격, 방어 (기본)
- 속도(턴 순서), 명중/회피, 분노 충전률 (잠정)

#### 결정 필요
- 흡수 1회당 정확한 경험치량 (동족 보너스 배수)
- 진화석 / 초월석 획득 경로 (보스 드롭? 상점? 이벤트?)
- 진화 시 랜덤 스킬 개수 (1개? 1~3개?)
- 스탯 분배 자동 vs 수동

### 3-6. 알 획득 경로

> [!tip] 핵심 원칙
> 드래곤은 **언제나 알 형태로만** 획득. 전투 직접 포획 없음.

| 경로 | 빈도 | 비고 |
|---|---|---|
| 👑 보스 노드 드롭 | 보장 | 단계 끝 보상 |
| 📦 상자 | 확률 | 희귀도/등급 다양 |
| 👤 NPC 보상 | 조건부 | 퀘스트 / 거래 |
| ⚔️ 일반 전투 드롭 | 낮은 확률 | 가끔 등장 |
| ❓ 이벤트 노드 | 선택지에 따라 | 분기 결과 |
| 🌐 [[#16. 교배 시스템\|교배]] | 모험 외 | 시즌 종료 종 / 조합 신규 종 획득의 주요 경로 |

### 3-7. 빈사 / 회복 시스템

#### 빈사(Knock-out)
- 드래곤 HP 0 → **사망 X / 빈사 상태**
- 빈사 드래곤은 **해당 모험 내에서 비활성화** (전투 불참)
- 모험 종료 후 자동 사망 X — **회복 가능**

#### 회복 수단

| 수단 | 위치 | 효과 |
|---|---|---|
| 🏥 **회복시설** | 모험 외 (마을/거점) | 빈사 → 정상 복구. **무료 + 시간 대기** / **비용 지불 시 단축** |
| 💊 **치료제(아이템)** | 모험 중 사용 | 빈사 즉시 부활 / HP 회복 |
| ❤️ **회복 노드** | 모험 중 단계 | HP 회복 (빈사 부활 ❌ 기본) |
| 💍 **부활 유물** | 회복 노드 진입 시 | **유물 보유 시 회복 노드에서 빈사도 부활 가능** |

> [!example] 부활 유물의 전략적 가치
> 깊은 단계(40+)에서는 빈사가 자주 발생 → 부활 유물 슬롯에 장착 시 회복 노드 가치 폭증.

#### 모험 실패 / 종료 시 보상 정책

> [!tip] 관대한 모델 (확정)
> 모험 중 획득한 **알 / 유물 / 화폐 / 단서는 그대로 가져옴**.
> 실패해도 손실 없음 → 부담 없는 도전 유도, 깊은 단계 시도 장려.

### 3-8. 아이템 시스템 (모험 한정 소모품)

> [!note] 슬레이 더 스파이어의 Potion 모델
> 아이템은 **모험 중에만 획득·사용**, **모험 외부로 가져갈 수 없음**.

#### 특징
- 모험 시작 시 인벤토리 비어있음
- 노드 보상 / 상자 / 이벤트로 획득
- 모험 종료 = 모든 아이템 소실

#### 아이템 카테고리 (예시)

| 종류 | 효과 |
|---|---|
| 💊 치료제 | 드래곤 HP 회복 / 빈사 부활 |
| ⚗️ 강화 물약 | 일시 공격력/방어력 상승 |
| 🔥 원소 부적 | 다음 전투에 속성 부여 |
| 🗝️ 열쇠 | 잠긴 상자/문 열기 |
| 💣 폭탄 | 전투 즉시 종료 (보스에는 효과 약함) |

### 3-9. 유물(Artifact) 시스템 ⭐

> [!tip] 슬레이 더 스파이어의 Relic 모델
> 유물은 **영구 보유** — 모험 외부로 들고 나갈 수 있다. 빌드의 핵심.

#### 특징
- **착용 슬롯 제한** 있음
- **슬롯은 캐릭터(플레이어 페르소나)에 바인딩** — 모험에 어떤 파티를 데려가도 동일 유물 효과 적용
- 슬롯 수는 **업그레이드로 확장**
- 모험 진입 전 슬롯에 장착 → 모험 내내 효과 유지

#### 슬롯 시스템

| 항목 | 값 |
|---|---|
| **시작 슬롯 수** | **3 슬롯** |
| **확장 방법** | **상점에서 구매** (재화 소모, 가격은 슬롯이 늘수록 상승) |
| **최대 (TBD)** | 8 ~ 10 |

> [!note] 슬롯 = 캐릭터 바인딩
> 플레이어 캐릭터는 시각적으로 노출되지 않지만 **계정 자체가 페르소나** 역할 — 유물 슬롯은 이 페르소나의 영구 진보(Meta-progression)다.

#### 유물 카테고리 (예시)

| 종류 | 효과 예시 |
|---|---|
| 🛡️ 방어 유물 | 모든 드래곤 방어 +10% |
| ⚔️ 공격 유물 | 첫 턴 공격 2배 |
| 💎 자원 유물 | 알 획득률 +5% |
| 🧙 단서 유물 | 단서 조각 발견 확률 +20% |
| 🎲 메타 유물 | 갈림길에서 노드 종류 1개 더 공개 |
| 🐲 종족 유물 | 특정 종 드래곤 강화 |

#### 데이터 구조 (유물)

```js
const artifact = {
  id: "ember_charm",
  name: "잿불 부적",
  rarity: "rare",
  slotCost: 1,            // 슬롯 점유 수
  effects: [
    { type: "stat_buff", target: "fire_dragons", attr: "atk", value: 0.1 },
    { type: "loot_modifier", target: "egg", value: 0.05 }
  ],
  acquireCondition: "stage_50_boss_drop"  // 또는 "season_master_reward"
}
```

> [!warning] 유물 = 메타 진보(Meta-progression)의 핵심
> 모험은 매번 리셋되지만 유물은 영구 → 장기 플레이 동기 유지.

### 3-11. 전투 메커닉 ⭐

> [!example] 카피바라고와 유사한 자동 턴제 + 일부 수동 개입

#### 기본 흐름
1. **자동 진행** — 매 턴 드래곤이 알아서 공격
2. 분노 게이지 채워지면 **분노 공격(궁극기)** 자동 발동
3. **스킬 수동 온/오프** — 플레이어가 각 드래곤의 스킬 자동 발동을 끌 수 있음 (자원 절약, 타이밍 조절)

#### 분노 게이지 (Rage Gauge)

| 항목 | 사양 |
|---|---|
| 단위 | **드래곤마다 개별** 게이지 |
| 충전 트리거 | 공격 / 피격 / 시간 (잠정) |
| 발동 | 가득 차면 자동 분노 공격 (스킬 OFF 시 보류) |
| 시각 표현 | 드래곤 아이콘 옆 / 아래 게이지 바 |

#### 속성 상성 (총 8속성, 시작 6 + 후속 2) ⭐

##### 시작 시즌 6속성 (확정)
- 🔥 **불** / 💧 **물** / 🌿 **풀** / ⚡ **번개** / 🪨 **땅** / ❄️ **얼음**

##### 후속 추가 2속성 (스토리/시즌 진행 시 등장)
- ☀️ **빛** / 🌑 **어둠**

> [!note] 후속 속성 도입의 의미
> 6 → 8 확장은 **세계관 전개의 일부**. 빛/어둠은 시즌 후반 보스/이벤트와 연결되어 메타 진보감 강화.

##### 상성 구조: **이중 삼각형 + 빛·어둠 대립** (확정)

```
[Triangle 1 — 생명 사이클]      [Triangle 2 — 지질 사이클]
   🔥 → 🌿 → 💧 → 🔥                🪨 → ⚡ → ❄️ → 🪨
   불 → 풀 → 물 → 불               땅 → 번개 → 얼음 → 땅

[대립 페어]
   ☀️ ↔ 🌑    빛 ↔ 어둠 (상호 강세)
```

##### 자연스러운 논리

| 관계 | 이유 |
|---|---|
| 🔥 > 🌿 | 풀을 태움 |
| 🌿 > 💧 | 뿌리가 물을 흡수 |
| 💧 > 🔥 | 물이 불을 끔 |
| 🪨 > ⚡ | 땅이 번개를 접지 |
| ⚡ > ❄️ | 번개로 얼음 갈라짐 |
| ❄️ > 🪨 | 동결로 바위 균열 |
| ☀️ ↔ 🌑 | 빛과 어둠은 서로의 천적 (상호 1.5×) |

##### 데미지 배율 매트릭스

| 공격 ↓ / 방어 → | 🔥 불 | 💧 물 | 🌿 풀 | 🪨 땅 | ⚡ 번개 | ❄️ 얼음 | ☀️ 빛 | 🌑 어둠 |
|---|---|---|---|---|---|---|---|---|
| 🔥 **불** | 1× | 0.5× | **1.5×** | 1× | 1× | 1× | 1× | 1× |
| 💧 **물** | **1.5×** | 1× | 0.5× | 1× | 1× | 1× | 1× | 1× |
| 🌿 **풀** | 0.5× | **1.5×** | 1× | 1× | 1× | 1× | 1× | 1× |
| 🪨 **땅** | 1× | 1× | 1× | 1× | **1.5×** | 0.5× | 1× | 1× |
| ⚡ **번개** | 1× | 1× | 1× | 0.5× | 1× | **1.5×** | 1× | 1× |
| ❄️ **얼음** | 1× | 1× | 1× | **1.5×** | 0.5× | 1× | 1× | 1× |
| ☀️ **빛** | 1× | 1× | 1× | 1× | 1× | 1× | 1× | **1.5×** |
| 🌑 **어둠** | 1× | 1× | 1× | 1× | 1× | 1× | **1.5×** | 1× |

> [!tip] 외우기 쉬움 — 핵심 규칙 3가지
> 1. **이중 삼각형** = 7개 관계만 기억 (각 속성: 강점 1 / 약점 1)
> 2. **빛 ↔ 어둠** 상호 1.5× (대립 페어)
> 3. **빛/어둠 ↔ 6속성** 완전 중립 (1×)

##### 설계 원칙
- 각 속성마다 **강점 1 / 약점 1** (대칭) → 무조건 강한/약한 속성 없음
- 두 삼각형 **독립** → 시즌 1(6속성) 만으로도 완결성
- 빛/어둠은 **별도 차원** → 후속 도입 시 "다른 격"의 연출 가능
- **5마리 파티의 다양성을 자연스럽게 강제** (한 속성 몰빵 불가)

##### 듀얼 속성

> [!warning] 보류 (확정)
> 듀얼 속성(드래곤이 2속성 동시 보유) 은 **시즌 1에서는 도입하지 않음**.
> 디자인 복잡도 폭증 우려. 후속 시즌에서 검토 가능.

##### 데이터 구조 (속성 상성)

```js
const elementMatrix = {
  // strong: 1.5x, weak: 0.5x, neutral: 1.0x
  fire:      { strong: ["grass"],     weak: ["water"] },
  water:     { strong: ["fire"],      weak: ["grass"] },
  grass:     { strong: ["water"],     weak: ["fire"] },
  earth:     { strong: ["lightning"], weak: ["ice"] },
  lightning: { strong: ["ice"],       weak: ["earth"] },
  ice:       { strong: ["earth"],     weak: ["lightning"] },
  light:     { strong: ["dark"],      weak: ["dark"] },   // 상호 강세
  dark:      { strong: ["light"],     weak: ["light"] }
};

function damageMultiplier(attackerEl, defenderEl) {
  if (elementMatrix[attackerEl].strong.includes(defenderEl)) return 1.5;
  if (elementMatrix[attackerEl].weak.includes(defenderEl))   return 0.5;
  return 1.0;
}
```

#### 결정 필요
- 분노 게이지 충전 정확한 공식
- 분노 공격 사용 후 게이지 리셋 / 부분 보존?
- 속성 종류 개수 (4개? 6개? 8개?)
- 빛/어둠처럼 특수 속성 도입?
- 듀얼 속성(2개 동시) 드래곤 도입?

## 10-N. 드래곤 네이밍 규칙 ⭐

> [!tip] 한글 친화 + 진화 격상 + 영문 병기
> 모든 드래곤 이름은 **한글 우선**, **진화 단계별 격상**, **영문 병기**의 3원칙을 따른다.

### 원칙 1. 진화 단계별 톤 격상 패턴

| 단계 | 한글 패턴 | 영문 패턴 | 분위기 |
|---|---|---|---|
| 🐣 **해츨링** | "~이" / 의태어 / 짧은 순한글 | 짧은 단어 (Ember, Sprout, Pebble) | 친근·캐릭터성 |
| 🐲 **성체** | 순한글 + "룡" 또는 한자어 + "룡" | 모티프 + Drake | 중성·격상 |
| ✨ **초월체** | 한자어 + "룡" (괄호로 한자 병기) | 위엄 있는 합성어 (Pyro, Tempest, Stormlord) | 위엄·전설 |

### 원칙 2. 속성·역할별 톤 분기

> [!note] 드래곤 성향에 맞춰 톤을 다변화
> 같은 진화 단계라도 **역할 / 스킬 분위기**에 따라 작명 톤을 달리 한다.

| 역할 | 톤 | 예시 (해츨링→성체→초월체) |
|---|---|---|
| 🗡️ **어택커** | 친근 → 격정 | 잿불이 → 불티룡 → 적염룡 |
| ❤️ **서포터** | 시적 · 우아 | 이슬이 → 청파룡 → 창천룡 |
| 🌀 **컨트롤** | 자연스럽고 깊이감 | 떡잎이 → 덩굴룡 → 천년수룡 |
| 🛡️ **탱커** | 든든하고 위엄 | 차돌이 → 바위룡 → 산악룡 |
| ⚡ **스피드 / 분노형** | 짧고 강렬 | 찌릿이 → 벼락룡 → 천뢰룡 |

### 원칙 3. 영문 병기 규칙

- 모든 드래곤 이름은 **한글 + 영문 병기** 의무
- 영문도 진화 단계에 따라 격상 (Ember → Ember Drake → Crimson Pyro)
- 한자어는 **괄호로 한자 병기** (예: 적염룡 (赤焰龍))

### 원칙 4. 종족 일관성

- **같은 종**의 모든 진화 단계는 시각적/이름의 **일관된 모티프** 유지
- 예: "잿불 → 불티 → 적염" 모두 *불의 강도 변화*를 표현하는 어휘
- 영문도 동일 모티프 (Ember 계열 유지)

### 작명 체크리스트

- [ ] 해츨링 이름이 친근한가? (~이, 의태어, 순한글)
- [ ] 성체 이름이 "룡"으로 끝나는가?
- [ ] 초월체 이름이 한자어 + 룡 형태인가?
- [ ] 영문 병기가 모든 단계에 있는가?
- [ ] 한자어 초월체에 한자 병기가 있는가?
- [ ] 3단계가 같은 모티프를 공유하는가?
- [ ] 드래곤 성향(역할)에 맞는 톤인가?

### 데이터 구조 (이름 필드)

```js
const dragonSpecies = {
  speciesId: "fire_drake",
  role: "attacker",                    // attacker | supporter | controller | tanker | rager
  element: ["fire"],
  names: {
    hatchling: { ko: "잿불이", en: "Ember" },
    adult:     { ko: "불티룡", en: "Ember Drake" },
    transcendent: { ko: "적염룡", hanja: "赤焰龍", en: "Crimson Pyro" }
  },
  innateSkill: "fire_breath",
  // ...
}
```

> [!warning] 다른 시즌 드래곤도 이 규칙 따를 것
> 이 규칙은 시즌 1 튜토리얼 5종에서 검증된 후, **모든 신규 드래곤 작명에 적용**한다.
> 자세한 작명 사례는 [[드래곤 종 카탈로그]] 참조.

## 11. 드래곤 예시 디자인

### 11-A. 시즌 1 튜토리얼 5종 (Common 티어)

> [!tip] 학습 곡선 설계
> 첫 모험에서 **다양한 부화 방식 + 흡수 시스템 + 노드 인식**을 자연스럽게 경험.
> 모두 시작 6속성 중 5가지를 커버 (얼음은 Hidden 티어로 후순위 배치).

#### 진화 단계별 이름 (드래곤마다 톤 다변화)

| # | 속성 | 🐣 해츨링 | 🐲 성체 | ✨ 초월체 | 영문 (해츨링 / 성체 / 초월체) |
|---|---|---|---|---|---|
| 1 | 🔥 불 (어택커) | **잿불이** | **불티룡** | **적염룡 (赤焰龍)** | Ember / Ember Drake / Crimson Pyro |
| 2 | 💧 물 (서포터) | **이슬이** | **청파룡 (靑波龍)** | **창천룡 (蒼天龍)** | Dewlet / Tide Drake / Azure Tempest |
| 3 | 🌿 풀 (컨트롤) | **떡잎이** | **덩굴룡** | **천년수룡 (千年樹龍)** | Sprout / Vine Drake / Eterna Sylvan |
| 4 | 🪨 땅 (탱커) | **차돌이** | **바위룡** | **산악룡 (山岳龍)** | Pebble / Boulder Drake / Mountainheart |
| 5 | ⚡ 번개 (분노 어택커) | **찌릿이** | **벼락룡** | **천뢰룡 (天雷龍)** | Zappy / Bolt Drake / Stormlord |

#### 부화 / 스킬 / 학습 목표

| # | 드래곤 (해츨링) | 부화 방식 | 종 고유 스킬 | 학습 목표 |
|---|---|---|---|---|
| 1 | 잿불이 | 10분 시간 대기 | **불꽃 강타** (단일 화염 데미지) | 기본 부화 흐름 |
| 2 | 이슬이 | 회복 노드 1번 통과 시 부화 진행 | **정화의 물결** (파티 1마리 회복) | 노드 종류 인식 |
| 3 | 떡잎이 | 모험 1회 완료 시 자동 부화 | **덩굴 잡기** (스턴 확률) | 모험 완수 보상 |
| 4 | 차돌이 | 알 흔들기 30회 | **단단한 등껍질** (방어 일시 ↑) | 입력형 부화 |
| 5 | 찌릿이 | 다른 알 1개 흡수 부화 | **감전** (분노 게이지 빠른 충전) | 흡수 시스템 |

> ❄️ **얼음 속성**은 시즌 1 후반 Hidden 티어 드래곤으로 배치 → 첫 미스터리 경험.

#### 학습 목표 매핑

| 시스템 | 어떤 드래곤이 가르침 |
|---|---|
| 시간 대기 부화 | 1️⃣ 잿불이 |
| 노드 종류 인식 | 2️⃣ 이슬이 (회복 노드) |
| 모험 완주 보상 흐름 | 3️⃣ 떡잎이 |
| 입력형(능동적) 부화 | 4️⃣ 차돌이 |
| 흡수 시스템 (퍼즐앤드래곤 핵심) | 5️⃣ 찌릿이 |
| 분노 게이지 시각 학습 | 5️⃣ 찌릿이 (스킬 효과) |
| 회복/서포트 역할 학습 | 2️⃣ 이슬이 (스킬 효과) |
| 탱커 역할 학습 | 4️⃣ 차돌이 (스킬 효과) |

> [!example] 5명이 곧 첫 파티
> 튜토리얼이 끝나면 자연스럽게 **속성 다양성 + 역할 다양성**을 갖춘 5마리 파티 완성.

### 11-B. 협력형 미스터리 5종 (Cryptic+ 티어)

#### 1) 별자리 드래곤 (Constellation / Stellaris)

- 12명에게 각각 별 1개 좌표 분배
- 합쳐서 별자리 완성
- 순서대로 클릭 → 별자리 이름 입력
- **최초 발견자만 정통**, 이후 변종

#### 2) 메아리 드래곤 (Echo)

- 알 설명에 랜덤 음절 1개
- 7명+ 음절 조합해 주문 완성 → 채팅창 입력
- 매주 음절 셔플

#### 3) 회유 드래곤 (Migration)

- 1시간마다 다른 바이옴 출현, **위치 비공개**
- 커뮤니티 목격 정보로 패턴 분석 → 다음 위치 예측

#### 4) 거울 드래곤 (Mirror)

- 두 플레이어가 알 절반씩 보유 (좌/우 비대칭)
- 같은 분 안에 트레이드 + **동시 클릭**

#### 5) 예언자 드래곤 (Oracle)

- 랜덤 플레이어에 예언서 조각 드롭
- 21개 모이면 의식 절차 공개 (요일 + 드래곤 3종 + 시각)

## 15. 시즌 시스템

### 개요

- 각 시즌마다 **정해진 드래곤 풀**이 있음
- 시즌이 끝나면 해당 드래곤들은 **발견 난이도가 대폭 상승** (감쇠 모델)
    - ⚠️ "발견 불가"가 아닌 **"점점 더 어려워짐"** — 신규 유저에게도 희망 유지
- 시즌 종료된 드래곤은 [[교배 시스템|교배(breeding)]]로도 획득 가능

### 15-1. 시즌 감쇠 모델 (Decay Model) ⭐

> [!warning] 핵심 메커닉
> 각 시즌이 지날 때마다 과거 드래곤은 점점 더 희박해진다.
> "발견 불가"가 아닌 **"추적의 묘미"**.

#### 단계별 감쇠 예시 (시즌 1의 불꽃 드래곤)

| 단계 | 시즌 | 난이도 | 출현 조건 |
|---|---|---|---|
| 활성 | 시즌 1 | 일반 | 화산 지역에 빈번히 출현 |
| 감쇠 1 | 시즌 2 | 어려움 | 출현률 1/5, 야간에만 |
| 감쇠 2 | 시즌 3 | 매우 어려움 | 출현률 1/20, 특정 NPC 퀘스트 클리어 시 |
| 잔재 | 시즌 4 | 희귀 | 보물상자 0.5%, 특정 의식 후 |
| 전설 | 시즌 5+ | 거의 불가 | 야생 출현 종료, 회상 이벤트 시 부활 |

#### 감쇠 메커니즘 옵션 (조합 가능)

- **출현률 감소**: 확률 단계적 하향
- **시간/조건 추가**: "특정 시간대만", "특정 아이템 보유 시만"
- **지역 축소**: 처음 3개 지역 → 2개 → 1개 → 비밀 지역
- **단계별 잠금 해제**: NPC 퀘스트 / 미니 ARG 클리어해야 만남 가능

#### 감쇠 모델의 장점

- 신규 유저가 **이론상 모든 드래곤을 만날 수 있음** (희망 유지)
- 고인물은 **추적의 묘미** (어디 있는지 찾아내는 재미)
- 시즌 마스터의 **희소성 가치 유지**

### 15-2. 시즌 간 스토리 연결 ✅

- 각 시즌은 **세계관 챕터**처럼 전개
- 예: "드래곤 군주의 봉인 → 봉인 해제의 조짐 → 군주의 귀환…"
- 시즌이 진행될수록 **세계가 변화** (지역 황폐화, 새 지역 개방)
- 과거 시즌 NPC들이 **현재 시즌에 흔적**을 남김 (편지, 비석, 메아리)

### 15-3. 시즌 교차 교배 ✅

- 시즌 N의 드래곤과 시즌 N+1의 드래곤을 **교배 가능**
- 결과로 **시즌 외 한정 신규 종** 등장 가능
- 자세한 메커닉: [[#16. 교배 시스템]]

### 15-4. 시즌 마스터 보상 ✅

> [!example] 시즌 도감 100% 달성자 혜택

| 보상 | 설명 |
|---|---|
| **시즌 마스터 칭호** | 영구 표시, 도감/프로필 노출 |
| **변종(Prismatic) 드래곤** | 시즌 한정 색상의 특별 변종 |
| **다음 시즌 얼리 액세스** | 1주일 먼저 시즌 N+1 진입 가능 |
| **회상 이벤트 우선권** | 과거 시즌 드래곤 재출현 시 우선 알림 |
| **특별 NPC 호의** | 마스터 전용 거래/퀘스트 잠금 해제 |

### 효과 정리

| 효과 | 설명 |
|---|---|
| **FOMO 강화** | "지금 잡는 게 가장 쉽다" → 시즌 중 활발한 플레이 |
| **후발주자 배려** | 감쇠 모델 + 교배로 결국 도달 가능 |
| **트레이딩 가치 상승** | 시즌 종료 종은 점점 희귀해짐 |
| **메타게임 깊이** | "어떤 시즌 종을 보존할까" 전략 |
| **장기 플레이 유도** | 시즌 마스터 → 다음 시즌 → 누적 명예 |

> [!note] 시즌제와 위키 박제 방지
> 시즌별 단서 셔플은 [[#14. 흔한 함정과 대응|위키 박제 함정]]의 자연스러운 해결책이기도 하다.

## 16. 교배 시스템

### 기본 규칙

- 교배에는 **드래곤 2마리** 필요
- 결과 가능 종:
    - 부모 두 종 중 하나
    - 두 종의 **조합으로 발생 가능한 신규 종**
- 조합 발견 자체가 또 하나의 콘텐츠 (어떤 조합이 어떤 결과를 내는지 실험)
- **시즌 종료 드래곤도 교배 결과로 등장 가능** → 신규 유저도 도감 완성 가능

### 조합 예시

| 부모 A | 부모 B | 가능한 결과 |
|---|---|---|
| 불 드래곤 | 물 드래곤 | 증기 드래곤 |
| 불 드래곤 | 땅 드래곤 | 용암 드래곤 |
| 시즌1 드래곤 A | 시즌2 드래곤 B | 시즌 외 한정 신규 종 C (오직 교배로만) |

### 데이터 구조

```js
const breedingRecipe = {
  parents: ["fire_dragon", "water_dragon"],
  possibleOutcomes: [
    { dragonId: "fire_dragon", weight: 30 },
    { dragonId: "water_dragon", weight: 30 },
    { dragonId: "steam_dragon", weight: 40 }  // 조합 신규
  ],
  cooldown: "7d",
  unlockCondition: null  // 또는 "discovered_steam_first"
}
```

> [!tip] 교배 + 발견 = 이중 보물찾기
> 어떤 조합이 어떤 드래곤을 만드는지 자체가 [[보물찾기]]의 또 다른 레이어다.
> 자세한 레시피는 [[교배 조합 레시피]] 문서 참조 (작성 예정).
